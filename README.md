# Entre Nós para Windows

Aplicativo para conversar, ligar e compartilhar a tela com seus amigos.

## Baixar

Use o arquivo Entre-Nos-Windows.zip na página de Releases. Extraia todos os arquivos e abra Entre Nos.exe. Entre com sua conta do Entre Nós.

Requer Windows 10/11 de 64 bits e conexão à internet. Versão portátil, sem instalador; os arquivos devem permanecer juntos na pasta extraída.

Este repositório distribui somente o aplicativo.
