# Discord do FrostNTJ para Windows

Baixe a versão mais recente em **Releases**. Extraia todo o ZIP e execute **Discord do FrostNTJ.exe** na pasta extraída.

Windows 10/11 de 64 bits. Aplicativo portátil: mantenha os arquivos juntos. Entre com a mesma conta do site.

Esta versão atualiza o nome do aplicativo. O endereço do serviço permanece o mesmo.
